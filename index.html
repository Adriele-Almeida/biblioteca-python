1. Operações com Arquivos

Ler início de arquivo grande

open().read(N)

Abre um arquivo de texto e lê apenas os primeiros N caracteres. Útil para inspecionar arquivos enormes sem carregar tudo na memória.

python -c "print(open(r'CAMINHO', encoding='utf-8', errors='ignore').read(5000))"

Ler final de arquivo grande

seek() + read()

Move o cursor para o fim do arquivo, volta N bytes e lê. Perfeito para ver logs recentes ou o final de exports grandes.

python -c "f=open(r'CAMINHO', encoding='utf-8', errors='ignore'); f.seek(0,2); size=f.tell(); f.seek(max(0,size-8000)); print(f.read())"

Ler arquivo completo em linhas

open().read().splitlines()

Lê o arquivo inteiro e divide em lista de linhas. Bom para processar conteúdo linha por linha.

python -c "
linhas = open(r'CAMINHO', encoding='utf-8', errors='ignore').read().splitlines()
for i, l in enumerate(linhas[:50], 1):
    print(f'{i}: {l}')"

2. Busca e Varredura de Pastas

Buscar arquivos por padrão (glob)

start_search / glob

Procura arquivos cujo nome contenha um padrão, em uma pasta ou recursivo. O asterisco (*) é curinga.

Get-ChildItem -Path 'PASTA' -Recurse -Force -ErrorAction SilentlyContinue | Where-Object { $_.Name -like '*PADRAO*' } | Select-Object -ExpandProperty FullName

Listar subpastas de uma pasta

Get-ChildItem -Directory

Mostra só as pastas dentro de um diretório, sem arquivos. Rápido para mapear estrutura.

Get-ChildItem -Path 'PASTA' -Directory -Force | Select-Object -ExpandProperty Name

Verificar unidades e espaço em disco

Get-PSDrive

Lista todos os discos do sistema com espaço usado e livre. Ajuda a saber onde tem folga.

Get-PSDrive -PSProvider FileSystem | Select-Object Name, Root, Used, Free | Format-Table -AutoSize

3. Contagem e Análise

Contar arquivos por pasta (Python)

os.walk()

Percorre uma pasta recursivamente somando arquivos. Mostra a contagem de cada pasta e o total geral.

python -c "
import os
pastas=[r'PASTA1', r'PASTA2']
t=0
for p in pastas:
    c=0
    if os.path.exists(p):
        for r,d,f in os.walk(p): c+=len(f)
        t+=c; print(f'{c:>8} | {p}')
    else: print(f'NAO EXISTE | {p}')
print('TOTAL:', t)"

Contar arquivos por pasta (PowerShell)

Measure-Object

Versão PowerShell do mesmo padrão. Usa Measure-Object para contar sem abrir cada arquivo.

$pastas=@('PASTA1','PASTA2'); $t=0; foreach($p in $pastas){ if(Test-Path $p){ $c=(Get-ChildItem -Path $p -Recurse -File -Force -ErrorAction SilentlyContinue | Measure-Object).Count; $t+=$c; Write-Output ('{0,8} | {1}' -f $c,$p) } else { Write-Output ('NAO EXISTE | {0}' -f $p) } }; Write-Output ('TOTAL: {0}' -f $t)

Contar sem duplicar subpastas

dedup por prefixo

Quando uma pasta contém outra que também deu match, evita contar duas vezes. Ordena por tamanho do caminho e só aceita pastas que não são subpasta de outra aceita.

$dirs=Get-ChildItem -Path 'J:\' -Recurse -Directory -Force -ErrorAction SilentlyContinue | Where-Object { $_.Name -like '*PADRAO*' } | Sort-Object { $_.FullName.Length }; $accepted=@(); $t=0; $lines=@(); foreach($d in $dirs){ $skip=$false; foreach($a in $accepted){ if($d.FullName.StartsWith($a.FullName+'\')){ $skip=$true; break } }; if(-not $skip){ $accepted+=$d; $c=(Get-ChildItem -Path $d.FullName -Recurse -File -Force -ErrorAction SilentlyContinue | Measure-Object).Count; $t+=$c; $lines+='{0,8} | {1}' -f $c,$d.FullName } }; $lines+=''; $lines+='TOTAL: '+$t; $lines+='PASTAS RAIZ: '+$accepted.Count; $lines | Out-File -FilePath 'SAIDA.txt' -Encoding UTF8

4. Processos e Saída

Executar comando e capturar saída

start_process

Dispara um comando no terminal e recebe a saída de volta. Base de todo o resto: é o motor que executa os outros padrões.

start_process
shell: powershell
command: SEU_COMANDO_AQUI
timeout_ms: 3000

Ler saída de processo em execução

read_process_output

Quando um comando demora mais que o timeout, ele continua rodando em background. Este padrão lê a saída parcial usando o PID retornado.

read_process_output
pid: NUMERO_DO_PID
length: 50
offset: 0
timeout_ms: 3000

Ler arquivo gerado por outro comando

read_multiple_files

Lê um ou vários arquivos de uma vez e devolve o conteúdo. Usado para pegar relatórios que um script salvou em disco.

read_multiple_files
paths: ["CAMINHO_DO_ARQUIVO"]

Verificar sessões ativas

list_sessions

Mostra se há algum processo ainda rodando em background. Evita disparar coisas em cima de execuções pendentes.

list_sessions

5. Varredura Web

Baixar página web

requests.get()

Faz uma requisição HTTP e baixa o HTML de qualquer URL. É o primeiro passo de qualquer automação na internet.

python -c "
import requests
r = requests.get('https://URL_AQUI', timeout=15)
print(r.status_code)
print(r.text[:3000])"

Extrair dados de HTML

BeautifulSoup

Lê o HTML baixado e extrai títulos, links, preços, o que você quiser, usando seletores CSS ou nomes de tags.

python -c "
import requests
from bs4 import BeautifulSoup
r = requests.get('https://URL_AQUI', timeout=15)
soup = BeautifulSoup(r.text, 'html.parser')
for a in soup.find_all('a', limit=10):
    print(a.get_text(strip=True), '->', a.get('href'))"

Controlar navegador real

Selenium

Abre um Chrome ou Edge de verdade, clica, digita, rola página. Para sites que exigem JavaScript ou login. Mais pesado que requests.

python -c "
from selenium import webdriver
from selenium.webdriver.common.by import By
driver = webdriver.Chrome()
driver.get('https://URL_AQUI')
print(driver.title)
campos = driver.find_elements(By.TAG_NAME, 'input')
print(len(campos), 'campos encontrados')
driver.quit()"

Busca no Google e salvar resultados

requests + BeautifulSoup (Google)

Combina download e extração para varrer resultados de busca, capturar títulos e URLs, e gravar num arquivo TXT.

python -c "
import requests
from bs4 import BeautifulSoup

headers = {'User-Agent': 'Mozilla/5.0'}
r = requests.get('https://www.google.com/search?q=TERMO+DE+BUSCA', headers=headers, timeout=15)
soup = BeautifulSoup(r.text, 'html.parser')
resultados = []
for a in soup.find_all('a', href=True):
    href = a['href']
    if href.startswith('/url?q='):
        url = href.split('/url?q=')[1].split('&')[0]
        if url.startswith('http'):
            resultados.append(a.get_text(strip=True) + ' | ' + url)
for res in resultados[:15]:
    print(res)
open('resultados_busca.txt', 'w', encoding='utf-8').write('\n'.join(resultados))"
